使用说明

如何在GitHub上管理您的健康数据

快速开始

部署步骤

  1. 在GitHub上创建一个新仓库（例如：health-tracker）
  2. 将 index.html 和 health-data.json 上传到仓库
  3. 在仓库设置中启用 GitHub Pages
  4. 访问 https://your-username.github.io/health-tracker/

添加每日数据

每天在GitHub仓库中编辑 health-data.json 文件：

  1. 打开仓库中的 health-data.json 文件
  2. 点击编辑按钮（铅笔图标）
  3. 在 records 数组中添加新的一天数据
  4. 提交更改（Commit changes）
  5. 刷新网页查看更新

数据格式示例

每天添加类似下面的数据块：

{ "date": "2024-01-17", "sleep": { "hours": 7.5, "quality": 8, "nightWakeups": 1 }, "exercise": { "minutes": 45, "steps": 8500, "intensity": "moderate" }, "diet": { "waterIntake": 2000, "vegetables": 300, "fruits": 200, "junkFood": 0, "caffeine": 2 }, "mood": { "score": 8, "stress": 4, "anxiety": 3 }, "physical": { "energy": 8, "fatigue": 3, "pain": 2 }, "vision": { "eyeFatigue": 5, "screenTime": 480 }, "notes": "感觉良好" }

字段说明

  • sleep.hours: 睡眠时长（小时）
  • sleep.quality: 睡眠质量评分（0-10）
  • exercise.minutes: 运动时长（分钟）
  • exercise.steps: 步数
  • diet.waterIntake: 饮水量（毫升）
  • mood.score: 心情评分（0-10）
  • physical.energy: 精力评分（0-10）
  • vision.screenTime: 屏幕使用时间（分钟）

  • ✅ 完整的版本控制，可查看历史修改
