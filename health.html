使用说明

如何在GitHub上管理您的健康数据

快速开始

部署步骤

  1. 在GitHub上创建一个新仓库（例如：health-tracker）
  2. 将 index.html 和 health-data.json 上传到仓库
  3. 在仓库设置中启用 GitHub Pages
  4. 访问 https://your-username.github.io/health-tracker/

每日运动目标设置

在 health-data.json 中添加每日运动完成情况，系统会自动计算达标率：

{ "date": "2024-01-15", "exerciseGoals": { "kegel": 30, // 凯格尔运动 (目标30个) "pushups": 30, // 俯卧撑 (目标30个) "running": 3.0, // 跑步 (目标3公里) "squats": 10, // 深蹲 (目标10个) "abdomen": 10, // 推腹 (目标10个) "plank": 1.0, // 平板支撑 (目标1分钟) "hiit": 2.0, // HIIT (目标2分钟) "burpees": 10 // 波比跳 (目标10个) }, "meditation": { "minutes": 10, // 冥想时长(分钟) "effect": 7 // 冥想效果(0-10) } }
